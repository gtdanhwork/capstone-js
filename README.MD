# CAPSTONE JS - PHONE SHOP

## Chức năng theo đề
- Website bán hàng + trang quản trị.
- SASS + Bootstrap + responsive.
- MockAPI/Axios.
- Product model.
- Hiển thị sản phẩm.
- Filter Samsung/iPhone.
- CartItem, thêm giỏ, tăng/giảm số lượng, remove.
- Tổng tiền, localStorage, checkout clear cart.
- Admin GET/POST/PUT/DELETE.
- Validation.
- Search theo tên.
- Sort giá tăng/giảm.

## Chạy
Dùng VS Code Live Server và mở `index.html`.

## MockAPI
Mở `assets/js/config.js`, thay `PRODUCT_API_URL` bằng URL resource `products` của nhóm.
Nếu chưa thay, project dùng dữ liệu demo để bạn test toàn bộ giao diện/nghiệp vụ.
